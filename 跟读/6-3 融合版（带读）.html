第一段

中文

我们再换个角度思考一下，当绝大多数人的注意时长都萎缩到2分钟以内，整个社会会发生什么变化呢——越来越多的人不知不觉放弃了文字的使用。2分钟都不到的注意时长，无法支撑任何有意义的阅读，也无法支撑任何深入思考。

日本語

▶もう一ひとつ別べつの角度かくどから考かんがえてみよう。▶大多数だいたすうの人々ひとびとの集中しゅうちゅうできる時間じかんが2分ふんないにまで縮小しゅくしょうしたとしたら、社会全体しゃかいぜんたいにはどのような変化へんかが起おこるのだろうか。▶その結果けっかとして、ますます多おおくの人々ひとびとが、知しらず知しらずのうちに文字もじを使つかうことをやめることになる。▶2分ふんにも満みたない集中力しゅうちゅうりょくでは、意味いみのあるまとまった文章ぶんしょうを読よむことも、ましてや物事ものごとを深ふかく考かんがえることもできない。

①“注意时长”＝人的注意力能够持续集中于某一对象或任务的时间长度；中文的“注意力”≠“专注力”，参考译文用「集中しゅうちゅうできる時間じかん／集中力しゅうちゅうりょく」；②“深入思考”译「物事ものごとを深ふかく考かんがえる」。

文中变形

考えてみよう ＝考かんがえる（v2 他）て形＋みる＋意志形：换个角度想想吧。

縮小したとしたら ＝縮小しゅくしょうする（n / v3 自他）＋たとしたら：假如萎缩到……。

やめることになる ＝辞やめる（v2 他）＋ことになる：会变得不再……。

満たない ＝満みたない（惯用）：不足、不到。

ましてや ＝adv：更何况。

深く考える ＝深ふかく考かんがえる（惯用）：深入思考。

第二段

中文

识字却基于种种原因并不使用文字的人，在行为模式上与“文盲”并无差异。他们不用文字输入（阅读），不用文字输出（表达）。很多所谓受过高等教育的人，到一定岁数后压根儿就不阅读、不写作，他们和所谓的“文盲”事实上是同一类人。

日本語

▶読よみ書かきの能力のうりょくを身みにつけていても、さまざまな理由りゆうで文字もじを使つかわない人ひとは、実際じっさいの行動こうどうにおいては「文盲もんもう」と何なにら変かわらない。▶彼らは文字もじによる入力にゅうりょく（読解どっかい）をせず、文字もじによる出力しゅつりょく（表現ひょうげん）も行おこなわない。▶いわゆる高等教育こうとうきょういくを受うけた人ひとの中なかにも、ある年齢ねんれいに達たっすると、まったく文章ぶんしょうを読よまず、文章ぶんしょうを書かかなくなる人ひとは少すくなくない。▶そうした人々ひとびとは、実際じっさいにはいわゆる「文盲もんもう」と本質的ほんしつてきに同おなじタイプになってしまっている。

“并无差异”的多种译法：〜と（全まったく）差さがない／〜と大差たいさない／〜と変かわらない／〜に等ひとしい。此处参考译文用「何なにら変かわらない」（毫无差别）。

文中变形

身につけていても ＝身みにつける（惯用）て形＋いても：即使具备（读写能力）。

変わらない ＝変かわらない（v1 自）否定：毫无差别。

行わない ＝行おこなわない（v1 他）否定：不做。

受けた ＝受うける（v2 他）过去形（连体）：受过（教育）的。

達すると ＝達たっする（v3 自）＋と：一到（某岁数）。

読まず ＝読よむ（v1 他）否定连用：不读。

なってしまっている ＝なる（v1 自）て形＋しまう＋ている：已经变成了。

第三段

中文

从电视出现，到短视频横行，科技进步终于带来了一个人类始料不及的副作用（或负作用），别说认真阅读了，你仔细观察一下，今天越来越多的人已经对2小时的电影失去了兴趣——根本坐不住。

日本語

▶テレビTVの登場とうじょうから、ショートshort動画どうがが広ひろく普及ふきゅうする現在げんざいに至いたるまで、科学技術かがくぎじゅつの進歩しんぽはついに人類じんるいが予想よそうもしなかった副作用ふくさよう（あるいは負ふの影響えいきょう）をもたらした。▶真剣しんけんな読書どくしょをしなくなったことは言いうまでもなく、注意深ちゅういぶかく観察かんさつしてみれば、今日きょうでは2時間じかんほどの映画えいがにすら興味きょうみを失うしなっている人ひとがますます増ふえていることに気きづくだろう……そもそも最後さいごまでじっと座すわって見み続つづけることができないのだ。

①“横行”的多种译法：横行おうこうする／はびこる／氾濫はんらんする／まかり通とおる。此处处理为「ショート動画どうがが広ひろく普及ふきゅうする」+「〜から…に至いたるまで」结构；②“始料不及”译「予想よそうもしなかった」；③“别说……了”译「〜は言いうまでもなく」。

文中变形

登場から ＝登場とうじょうする（n / v3 自）＋から：从……出现。

至るまで ＝至いたる（v1 自）＋まで：一直到……。

予想もしなかった ＝予想よそうする（n / v3 他）＋も＋しなかった：始料不及的。

もたらした ＝齎もたらす（v1 他）过去形：带来了。

言うまでもなく ＝言いうまでもなく（惯用）：不用说……。

興味を失っている ＝興味きょうみを失うしなう（惯用）て形＋いる：对……失去兴趣。

座って見続ける ＝座すわる（v1 自）て形＋見み続ける（v2 他）：坐着一直看。

第四段

日本語

▶歴史認識れきしにんしきよりも深刻しんこくに憂慮ゆうりょすべきは、首相主導しゅしょうしゅどうで進すすめられている政策せいさくが「戦前回帰せんぜんかいき」を志向しこうしていることです。▶まさに「富国強兵ふこくきょうへい」路線ろせんというほかありません。▶殺傷能力さっしょうのうりょくのある武器輸出ぶきゆしゅつの解禁かいきんは、武器生産ぶきせいさんの国際競争力こくさいきょうそうりょくを高たかめながら有事ゆうじに備そなえる目的もくてきです。▶日本にほんが武器輸出ぶきゆしゅつ大国たいこくだった戦前戦中せんぜんせんちゅうも似にた理屈りくつで軍需産業ぐんじゅさんぎょうを振興しんこうしました。▶財政事情ざいせいじじょうが苦くるしい中なかで防衛費ぼうえいひの増額ぞうがくを目指めざし、肝心かんじんの国民生活こくみんせいかつは豊ゆたかさの実感じっかんに乏とぼしいことも戦前戦中せんぜんせんちゅうと共通きょうつうします。

中文

比历史认识问题更令人担忧的是，在首相主导下推行的一系列政策，正在呈现出“回归战前”的倾向。这无疑是在走“富国强兵”的路线。放开具有杀伤能力的武器出口，旨在提升日本武器制造业国际竞争力的同时，为紧急事态做准备。在战前及战争期间，日本也曾是武器出口大国，当时同样以类似的理由大力发展军需产业。如今，日本在财政状况吃紧的情况下仍力主增加防卫费，而普通民众却难以切身感受到生活的富足，这一点与战前及战争期间颇为相似。

①「志向しこうする」＝追求、倾向于……（意识、思想、行为朝着某个方向发展）；②基于读者意识，“富国强兵”处可作加法处理（补出“明治时期”背景，见文末强化笔记）；③「まさに〜というほかありません」＝正是……、只能说是……。

文中变形

憂慮すべき ＝憂慮ゆうりょする（n / v3 他）＋べき：应当担忧的。

進められている ＝進すすめる（v2 他）被动て形＋いる：正在推行的。

志向している ＝志向しこうする（n / v3 他）て形＋いる：正在朝着……方向。

ほかありません ＝惯用（〜というほかありません）：只能说是……。

高めながら ＝高たかめる（v2 他）＋ながら：一边提升……一边。

備える ＝備そなえる（v2 自他）连体修饰：为……做准备。

振興しました ＝振興しんこうする（n / v3 他）过去形：大力发展了。

目指し ＝目指めざす（v1 他）连用形：以……为目标。

乏しい ＝乏とぼしい（イ形）：匮乏、难以（感受到）。

共通します ＝共通きょうつうする（n / v3 自）基本形：与……相同。

中文

在之前结束的特别国会上，一系列带有“回归战前”色彩的法律相继获得通过。此次修订《皇室典范》仍执意坚持皇位由男系继承，其背景无非是战前及战争期间的“皇国史观”。设立“毁坏国旗罪”以及制定《国家情报会议设置法》，让人联想到战前及战争期间那种民众彼此窥探思想、相互监视的压抑社会气氛。

ほかなりません ＝惯用（〜にほかならない）：无非是……。

立ち入って ＝立たち入いる（v1 自）て形：介入、窥探。

相互監視した ＝相互監視そうごかんしする（n / v3 他）过去形（连体）：互相监视的。

通じます ＝通つうじる（v2 自）基本形：与……相通、一脉相承。

笔强化笔记精讲（瑞译）

第一段注意时长与心理学词汇

“注意时长”：在心理学中与“注意的稳定性”密切相关，指“人的注意力能够持续集中于某一对象或任务的时间长度”。注意：中文的“注意力”不等于“专注力”——注意力是被对象吸引、转移过去的能力或状态（如手机一响就看了一眼），不要求长时间持续；专注力则是把注意持续集中在同一个对象或任务上的能力（如连续半小时不分心看书）。

考试心理学词汇：集中力しゅうちゅうりょく（专注力，集中力しゅうちゅうりょくが高たかまる／低下ていかする）；思考しこう／考かんがえる力ちから（思考，思考しこうを深ふかめる／論理ろんり的に考かんがえる）；感情かんじょう（感情，感情かんじょうを抱いだく／ネガティブな感情かんじょう——中文“情绪”多对应「感情かんじょう」而非「情緒じょうちょ」）；不安ふあん（焦虑，将来しょうらいへの不安ふあん／不安ふあんを感かんじる）；共感きょうかん（共鸣，共感きょうかんする／共感きょうかんを呼よぶ）。

第二段“并无差异”的多种译法

“并无差异”近义表达有“和……没有区别／和……一致／大同小异／无异于……”。日译可有多种：

  • 〜と（全まったく）差さがない：最直接客观，适合数据比较、调查研究、客观分析。例：二つの群ぐんの会話頻度かいわひんどの割合わりあいにほとんど差さはない。
  • 〜と大差たいさない：没有太大不同。例：これならどれでも大差たいさない。
  • 〜と変かわらない：与……别无两样。例：日本にほんと変かわらない環境かんきょうで過すごしている。
  • 〜に等ひとしい：等同于……、无异于……。例：プライバシーはほとんどないに等ひとしい。

第三段“横行”的四种译法

“横行”本义为行为蛮横、仗势作恶，也常引申为令人反感的事物“大量出现、肆意盛行”。日语译法多样：

  • 横行おうこうする：坏事频繁发生、肆意妄为。与“横行”最接近，常与詐欺さぎ、汚職おしょく、犯罪はんざい等负面行为搭配。例：インターネット上じょうには模倣品もほうひんや海賊版かいぞくばんも横行おうこうしている。
  • はびこる：不好的事物势力越来越强并不断扩散，强调“像杂草一样滋生蔓延”。例：独善どくぜんと独断どくだんがはびこる今いまの時代じだい。
  • 氾濫はんらんする：不好的东西传播开来、泛滥成灾，强调“数量太多、到处都是”。例：情報じょうほうが氾濫はんらんしている今いまの時代じだい。
  • まかり通とおる：“通る／通用する”的加强表达——不合理的东西堂而皇之地得到认可、通行。例：一国主義いっこくしゅぎがまかり通とおることは不可能ふかのうだ。

第四段「志向する」与“富国强兵”的加法处理

「志向しこうする」：意识、思想、行为等朝着某个方向发展，可译为“追求……”“倾向于……”“以……为导向”。拓展：安全志向あんぜんしこう（重视安全）、健康志向けんこうしこう（追求健康）、上昇志向じょうしょうしこう（有上进心）。注意与「志こころざす」区分——「志す」是下决心去做某件事、朝自己心中确定的目标前进（学問がくもんに志こころざす），多跟梦想、职业等个人理想；「志向しこうする」则强调意识、思想、行为朝着某个方向发展。

“富国强兵”的加法处理（基于读者意识）：中文读者可能 get 不到“富国强兵”所指的时代背景，可补出「明治時期」——“这无疑是在走明治时期的‘富国强兵’路线”。这样处理以后时代信息更明确，更有助于中文读者理解原文的历史指涉。考试翻日译中时如果拿不准，可以保守一些，不轻易增加原文没有的连接词；但译中（尤其是新闻等面向普通中文读者的文本）则可根据读者意识适度补出原文隐含的衔接。

段落衔接示意：判断“正在走富国强兵路线”→证据1：放宽武器出口、发展军需→历史对照：战前战中也是如此→证据2：财政吃紧仍增防务费，而民众缺乏富足感→再次与战前战中对照。

第五段「軒並み」与「相次いで」「続々と」辨析

「軒並のきなみ」：原指房屋鳞次栉比、每家每户，副词化后表示某一范围内的对象“无一例外地、普遍地呈现出相同状态”，可译为“纷纷、普遍、几乎无一例外”。常与价格、指数、业绩等整体性变化搭配：軒並のきなみ上昇じょうしょうする／軒並のきなみ値上ねあがりする。

辨析：

  • 軒並のきなみ：强调“范围广，大家都这样”。例：旅行業界りょこうぎょうかいは軒並のきなみ活気かっきづいた。
  • 相次あいついで：强调“一件接着一件发生”。例：殺人さつじんが相次あいついで起おこる。
  • 続々ぞくぞくと：强调“接二连三、源源不断”。例：見物人けんぶつにんが続々ぞくぞくと入場にゅうじょうする。

“皇国史观”补充：战前及战争期间以天皇为中心的历史观，是《皇室典范》修订“执意男系继承”的思想背景。另外“男系”处理为“父系”亦可，但中文官方媒体常见的“只能由男性继承”是错误理解。
